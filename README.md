# Мария Курочкина — сайт-портфолио

Одностраничный сайт фотографа. Статика, без сборки и зависимостей: открывается
как есть, разворачивается на GitHub Pages.

**Живая версия:** https://xdshn.github.io/gedris.art/

---

## Что внутри

```
index.html              вся разметка страницы
assets/css/style.css    дизайн-система и вёрстка
assets/css/fonts.css    подключение локальных шрифтов
assets/fonts/           Oswald + JetBrains Mono (woff2, кириллица и латиница)
assets/js/main.js       фильтр жанров, полноэкранный просмотр, анимации
assets/img/grid/        превью для сетки (webp, высота 820 px)
assets/img/full/        версии для полноэкранного просмотра (webp, до 2400 px)
assets/img/misc/        логотип и снимки публикации в прессе
tools/build.py          пересборка галереи из исходников
```

## Дизайн

Тёмная база и один-единственный источник цвета — **хроматический блик от
объектива**. Он живёт в логотипе, в первом экране, в подчёркиваниях и наведениях;
на фотографии ничего не накладывается — кадры показываются чистыми.

Шрифты: **Oswald** для заголовков, **JetBrains Mono** для интерфейса и подписей.
Файлы лежат в репозитории, а не подтягиваются с Google Fonts — у российской
аудитории тот CDN часто недоступен.

Сетка работ — justified rows: каждый кадр растёт пропорционально своему
соотношению сторон, поэтому ряд заполняет ширину целиком, а фотография
не кропается.

Чтобы убрать зерно на блике целиком, поставьте `--grain: 0` в `assets/css/style.css`.

## Как обновить галерею

1. Сложите отобранные исходники в любую папку.
2. Опишите их в JSON:

```json
[
  {
    "src": "/путь/к/кадру.jpg",
    "genre": "concert",
    "title": "Дима Билан",
    "cap": "Концерт · сцена"
  }
]
```

Доступные `genre`: `concert`, `event`, `fashion`, `art`, `object`, `nature`.
Кнопки фильтра и счётчики собираются автоматически — показываются только
непустые жанры.

3. Запустите сборку:

```bash
python3 tools/build.py selection.json                 # пути в src абсолютные
python3 tools/build.py selection.json /путь/к/архиву  # пути в src относительные
```

В `tools/selection.json` лежит текущий отбор — 69 кадров с путями относительно
корня папки из Google Drive. Чтобы пересобрать сайт из того же архива:

```bash
python3 tools/build.py tools/selection.json "/путь/к/скачанной/папке"
```

Скрипт сам сделает превью и полноразмерные версии, посчитает пропорции,
подставит размытые заглушки на время загрузки и вклеит разметку в `index.html`
между метками `<!-- WORKS:START -->` и `<!-- WORKS:END -->`.

Заодно он находит и срезает служебную плашку триальной Movavi, если она
осталась в углу кадра.

Нужен Python 3 и Pillow: `pip install pillow`.

## Как добавить портрет автора

Сейчас в блоке «Об авторе» стоит заглушка с монограммой. Когда появится
портрет, положите его в `assets/img/misc/portrait.webp` и замените в
`index.html` содержимое `.portrait-slot`:

```html
<div class="portrait-slot">
  <img src="assets/img/misc/portrait.webp" alt="Мария Курочкина" width="800" height="1000">
</div>
```

Пропорции блока — 4:5.

## Деплой

Settings → Pages → Source: ветка с сайтом, папка `/ (root)`.
Файл `.nojekyll` уже лежит в корне — он отключает обработку Jekyll.

Все пути относительные, поэтому сайт одинаково работает и на поддомене
проекта, и на своём домене. Чтобы подключить `gedris.art`: Settings → Pages →
Custom domain, а у регистратора — `A`-записи на `185.199.108.153`,
`185.199.109.153`, `185.199.110.153`, `185.199.111.153` (или `CNAME`
на `xdshn.github.io` для поддомена вроде `www`).
