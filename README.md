# Мария Гедрис — сайт-портфолио

Одностраничный сайт фотографа. Статика, без сборки и зависимостей: открывается
как есть, разворачивается на GitHub Pages.

**Живая версия:** https://xdshn.github.io/gedris.art/

---

## Что внутри

```
index.html              вся разметка страницы
404.html                страница «не туда» в том же стиле
robots.txt sitemap.xml  для поисковиков
assets/css/style.css    дизайн-система и вёрстка
assets/css/fonts.css    подключение локальных шрифтов
assets/fonts/           Oswald + JetBrains Mono (woff2, кириллица и латиница)
assets/js/main.js       фильтр, просмотр с зумом, выключка имени, анимации
assets/img/grid/        превью для сетки (webp, высота 820 px)
assets/img/grid-sm/     то же для телефонов (webp, высота 460 px)
assets/img/full/        версии для полноэкранного просмотра (webp, до 2400 px)
assets/img/misc/        логотип, иконки и снимки публикации в прессе
tools/build.py          пересборка галереи из исходников
tools/selection.json    текущий отбор: 62 кадра с подписями
```

## Дизайн

Тёмная база и один-единственный источник цвета — **хроматический блик от
объектива**. Он живёт в логотипе-кольце, в подчёркиваниях и наведениях;
на фотографии ничего не накладывается — кадры показываются чистыми.

**Фон общий на всю страницу.** Фиксированный слой под контентом: цветные пятна
и призматическая полоса плывут по мере прокрутки с разной скоростью и ходят
по кругу, поэтому секции читаются как один кадр, а не как набор отдельных
экранов. Яркость фона привязана к галерее — там, где идут фотографии, он
приглушается и не спорит с ними.

Блок «Где снимала» берёт цвет построчно: у каждой строки свой оттенок спектра,
он въезжает слева при наведении. Все состояния — только трансформации
и прозрачность, без перерасчёта раскладки.

Шрифты: **Oswald** для заголовков, **JetBrains Mono** для интерфейса и подписей.
Файлы лежат в репозитории, а не подтягиваются с Google Fonts — у российской
аудитории тот CDN часто недоступен.

Сетка работ — justified rows, ряды выкладывает скрипт: он подбирает высоту
строки так, чтобы она заполнила ширину при точных пропорциях кадров.
Пустых хвостов не остаётся, фотографии не кропаются вообще — искажение
пропорций держится в пределах 0.01%.

**Вступление.** Страница открывается загрузчиком (не меньше 1.1 с, не больше
3.2 с), затем слева влетает камера и встаёт справа с лёгким разворотом,
под ней проявляется имя, следом — цветное облако и атрибуты фотографа:
карты памяти, кардридер, объектив, вспышка, отражатель, ремешок, аккумулятор,
крышка и светофильтр. Всё нарисовано вектором и живёт в общей световой гамме;
камера стилизованная, без чужих логотипов. Системная настройка «уменьшить
движение» показывает первый экран сразу, без вступления.

Имя на первом экране выключено по ширине: обе строки идут одним кеглем, а по
краям выравниваются трекингом — скрипт подбирает его так, чтобы правые края
совпадали на любом экране. Сквозь буквы медленно проходит блик.

Чтобы убрать зерно на блике целиком, поставьте `--grain: 0` в `assets/css/style.css`.

## Что умеет страница

- **Просмотр кадра.** Открывается целиком, без обрезки. Масштаб — двойным
  кликом, кнопками или щипком на телефоне, до 600%. Колесо намеренно не
  масштабирует: на тачпадах это работает рывками. Приближенный кадр
  двигается перетаскиванием и не отрывается от краёв. Листается стрелками,
  свайпом и лентой превью; `0` возвращает масштаб, `Esc` закрывает.
  Фокус заперт внутри окна, лента превью — один таб-стоп со стрелками.
- **Фильтр по жанрам** без перезагрузки, с подсчётом и объявлением результата
  для скринридеров. Кнопка «показать ещё» показывает ровно столько, сколько
  осталось, и прячется, когда показывать больше нечего.
- **Отзывчивые картинки:** телефон грузит версии вдвое меньше десктопных,
  первый кадр сетки подгружается заранее.
- **Появление карточек:** восемь разных анимаций входа раздаются по таблице,
  так что соседние карточки ведут себя по-разному. Эффекты живут на внутреннем
  слое: обнулять площадь самой карточки нельзя — наблюдатель пересечений
  перестаёт её видеть и она не появится никогда.
- **Свет:** блик идёт за курсором на первом экране, подсвечивает плитки и
  кнопки под указателем, проходит по заголовкам при появлении. Всё отключается
  системной настройкой «уменьшить движение».

## Как обновить галерею

1. Сложите отобранные исходники в любую папку.
2. Опишите их в JSON:

```json
[
  {
    "src": "/путь/к/кадру.jpg",
    "genre": "concert",
    "title": "Дима Билан",
    "cap": "Концерт · сцена"
  }
]
```

Доступные `genre`: `concert`, `event`, `fashion`, `art`, `object`, `nature`.
Кнопки фильтра и счётчики собираются автоматически — показываются только
непустые жанры.

3. Запустите сборку:

```bash
python3 tools/build.py selection.json                 # пути в src абсолютные
python3 tools/build.py selection.json /путь/к/архиву  # пути в src относительные
```

В `tools/selection.json` лежит текущий отбор — 62 кадра с путями относительно
корня папки из Google Drive. Чтобы пересобрать сайт из того же архива:

```bash
python3 tools/build.py tools/selection.json "/путь/к/скачанной/папке"
```

Скрипт сам сделает превью и полноразмерные версии, посчитает пропорции,
подставит размытые заглушки на время загрузки и вклеит разметку в `index.html`
между метками `<!-- WORKS:START -->` и `<!-- WORKS:END -->`.

Заодно он находит и срезает служебную плашку триальной Movavi, если она
осталась в углу кадра.

Нужен Python 3 и Pillow: `pip install pillow`.

## Как добавить портрет автора

Сейчас в блоке «Об авторе» стоит заглушка с монограммой. Когда появится
портрет, положите его в `assets/img/misc/portrait.webp` и замените в
`index.html` содержимое `.portrait-slot`:

```html
<div class="portrait-slot">
  <img src="assets/img/misc/portrait.webp" alt="Мария Гедрис" width="800" height="1000">
</div>
```

Пропорции блока — 4:5.

## Деплой

Settings → Pages → Source: ветка с сайтом, папка `/ (root)`.
Файл `.nojekyll` уже лежит в корне — он отключает обработку Jekyll.

Все пути относительные, поэтому сайт одинаково работает и на поддомене
проекта, и на своём домене. Чтобы подключить `gedris.art`: Settings → Pages →
Custom domain, а у регистратора — `A`-записи на `185.199.108.153`,
`185.199.109.153`, `185.199.110.153`, `185.199.111.153` (или `CNAME`
на `xdshn.github.io` для поддомена вроде `www`).
